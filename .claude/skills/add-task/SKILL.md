# タスク追加（GitHub Issue 起票）

以下の内容で GitHub Issue を作成してください。

**タスク内容:**
$ARGUMENTS

## 手順

1. 引数のタスク内容から、以下の3項目を整理する:
   - **タイトル**: 簡潔な1行（連番プレフィクス（`Task XX:` 等）は付けない）
   - **背景**: なぜこのタスクが必要か。解決したい課題やユーザー価値。**引数から背景が明言されていない場合、推測で埋めない。必ずユーザーに確認して実際の理由を聞く**
   - **ユーザー視点での変更内容**: 何が変わるか（画面・操作・挙動）。ソースコード（ファイル名・関数名等）には触れず、エンドユーザーが体感する変化として記述
   - **完了条件**: ユーザーが体感できる完了基準
2. 内容が曖昧・情報不足の場合はユーザーに確認してから作成する（特に背景/Whyは推測せず必ず確認する）
3. 以下のコマンドで Issue を作成:
   ```bash
   gh issue create --title "<タイトル>" --body "$(cat <<'EOF'
   ## 背景
   <なぜ必要か>

   ## ユーザー視点での変更内容
   <何が変わるか。画面・操作・挙動>

   ## 完了条件
   <ユーザーが体感できる完了基準>
   EOF
   )"
   ```
4. 作成された Issue 番号と URL をユーザーに報告する

## 注意事項

- 本文にはソースコードの実装詳細（ファイル名・クラス名・関数名等）を含めない（ユーザー視点で記述）
- タイトルに `Task XX:` のような連番プレフィクスは付けない（GitHub Issue 番号で識別するため）
- 既存の関連 Issue がありそうな場合は、`gh issue list` で重複を確認してから作成する
